# ズボラ家計簿 📷💪

「なかなか続かない」人のための家計簿アプリ（スマホブラウザ向けPWA）。
レシートを写メで撮るだけで自動入力、そして **使いすぎを防ぐためのオリジナル機能** を詰め込みました。

## 特長

- **📷 レシート撮影で自動入力** — 写真から店名・日付・金額・品目・カテゴリをClaudeの画像認識で抽出。手入力の手間をほぼゼロに。
- **📅 「あと何日」メーター** — 「残り◯円」ではなく *今のペースだと残高があと何日もつか* を表示。金欠になりやすい人向けの直感的な残量バー。
- **⏳ 衝動買いクールダウン** — 欲しいモノはまず「欲しいリスト」へ登録 → 数日待ってから「買う / 我慢する」を判定。勢いの出費をブロック。
- **💪 我慢貯金** — 買わずに我慢した額が *仮想の貯金* として貯まっていく。「使わない＝増える」で節約をゲーム化（世の中に意外とない発想）。
- **⭐ 後悔メーター** — 買ったものに満足度（★1〜5）を記録。後悔しがちなカテゴリを学習し、次に同じカテゴリで支出しようとすると「本当に必要？」とそっと警告。

## 使い方（セットアップ）

必要なもの: Node.js 18 以上

```bash
# 1. 依存をインストール
npm install

# 2. 環境変数を用意（レシートOCRを使う場合）
cp .env.example .env
#   .env を開いて ANTHROPIC_API_KEY を設定
#   （https://console.anthropic.com/ で発行）
#   ※ キーが無くても、手入力で全機能使えます

# 3. 起動
npm start
```

ブラウザで `http://localhost:3000` を開きます。
スマホで使うときは、同じネットワークから `http://<PCのIP>:3000` を開き、
ブラウザの「ホーム画面に追加」をするとアプリのように使えます（PWA）。

## 画面構成

| タブ | 内容 |
| --- | --- |
| 🏠 ホーム | あと何日メーター / 我慢貯金 / 1日の目安・着地予測 / 判定待ち通知 |
| 📷 追加 | レシート撮影 → 自動入力、または手入力で支出を記録 |
| 🛒 欲しい | 衝動買いクールダウン。欲しいモノを登録し、冷却後に判定 |
| 📋 履歴 | 今月の支出一覧。各支出に満足度（後悔メーター）を記録 |
| ⚙️ 設定 | 月の予算 / クールダウン既定日数 / 我慢貯金の目標額 / OCR状態 |

## 技術構成

- **バックエンド**: Node.js + Express（`server.js`）
- **データ保存**: JSONファイル（`data/db.json`、個人利用前提でDB不要）
- **OCR**: Anthropic Claude の画像認識（`lib/ocr.js`）
- **フロント**: ビルド不要のバニラJS製PWA（`public/`、Service Worker + manifest）

```
server.js          APIサーバー
lib/store.js       JSONデータ保存
lib/ocr.js         レシート画像 → 構造化データ
lib/insights.js    あと何日 / 我慢貯金 / 後悔メーターの計算
public/            PWAフロントエンド
```

## データについて

すべて `data/db.json` にローカル保存されます（このファイルは `.gitignore` 済み）。
バックアップしたいときはこのファイルをコピーしてください。

## メモ

- レシートOCRはAPI利用のため、読み取り1回ごとにごくわずかな費用が発生します。
- 送信前に画像を自動で縮小して通信量を抑えています。
